Froditor

Enkel tekstbehandlar for Linux · versjon @VERSION@

Installer (Debian, Ubuntu, Mint …)

wget -O /tmp/froditor.deb https://frodolini.github.io/Froditor/froditor_latest_all.deb
sudo apt install /tmp/froditor.deb

Pakka legg sjølv til denne kjelda, så nye versjonar kjem med vanleg oppdatering:

sudo apt update && sudo apt upgrade

Avinstaller

sudo apt purge froditor

Kjeldekode: github.com/Frodolini/Froditor
